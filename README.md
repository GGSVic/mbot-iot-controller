## Project Overview

This project integrates multimedia playback, wireless communication, embedded systems, and mobile robotics into a single platform.

A desktop application running on a Raspberry Pi 4 provides an interface capable of controlling both an MP3 player and an MBot mobile robot. Communication between software and hardware is achieved through Firebase Realtime Database, allowing bidirectional communication between the desktop application and the embedded devices.

The system also incorporates an SSD1306 OLED display for multimedia feedback and an infrared remote control capable of interacting with the application remotely through the ESP32 communication module.

---

## System Components

### Raspberry Pi 4

Runs the desktop application developed in Python and PyQt5.

Responsibilities:

- MP3 playback.
- Playlist management.
- Song metadata visualization.
- OLED display updates.
- MBot control interface.
- Firebase communication.
- Processing events generated by the robot.

---

### Desktop Application

The graphical interface combines multimedia and robotic control features into a single application.

Features:

- Play, Pause and Stop controls.
- Previous and Next track selection.
- Song progress control.
- Playlist visualization.
- Song metadata extraction (Title, Artist and Album).
- MBot directional controls.
- Processing of commands received through Firebase.

---

### ESP32 Communication Module

Acts as the communication gateway between the Raspberry Pi application and the MBot platform.

Responsibilities:

- WiFi connectivity.
- Firebase communication.
- UART communication with the Arduino Mega.
- Reception of commands from an infrared remote control.
- Publishing multimedia commands to Firebase.
- Forwarding sensor information to Firebase.

---

### Infrared Remote Control

An infrared remote control can interact directly with the ESP32.

Supported actions include:

- Play / Pause.
- Next track.
- Previous track.
- Stop playback.
- Direct song selection through numeric input.

Commands received by the ESP32 are interpreted and published to Firebase, allowing the desktop application to react accordingly.

---

### MBot Platform

The MBot platform is controlled by an Arduino Mega running FreeRTOS.

Responsibilities:

- Motor control.
- Execution of movement commands.
- Sensor monitoring.
- Event generation.
- Communication with the ESP32 through UART.

---

### OLED Display (SSD1306)

An SSD1306 OLED display connected to the Raspberry Pi provides real-time multimedia information.

Displayed information includes:

- Song title.
- Artist.
- Album.

---

## Communication Architecture

### Raspberry Pi ↔ Firebase

The desktop application exchanges information through Firebase Realtime Database.

Examples:

- Movement commands.
- Multimedia commands.
- Song selection.
- Sensor events.

### ESP32 ↔ Firebase

The ESP32 continuously monitors Firebase and publishes events generated by the infrared remote control and robot hardware.

### ESP32 ↔ Arduino Mega

Communication between the ESP32 and MBot controller is performed through UART serial communication.

### Remote Control → ESP32 → Firebase → Desktop Application

Remote control commands are received by the ESP32, interpreted, uploaded to Firebase, and then processed by the desktop application.
