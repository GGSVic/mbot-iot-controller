# Assets

This directory contains the resources used by the desktop application.

## Images

The `images/` directory contains graphical assets used by the user interface, including icons and application resources.

## Songs

The `songs/` directory contains a reduced set of audio files intended for demonstration purposes only.

The original project was developed using a music library of approximately 100 songs. To keep this repository lightweight and focused on preserving the software architecture, only a small subset of short demo clips has been included.

These demo files were trimmed to a few seconds in duration and are provided solely to demonstrate the functionality of the integrated MP3 player.

The original music collection is not included in this repository.

If available, the original song library can be obtained from:

**[https://drive.google.com/file/d/18tNj6cWb5WoHzQnHslxK35hPU4t4MOXV/view?usp=sharing]**

## Notes

This repository is preserved as an academic project archive. The assets included here are intended only to provide enough resources to understand and demonstrate the application's functionality.
