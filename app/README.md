# Desktop Application

This directory contains the PyQt5 desktop application used to control the MBot and manage multimedia playback.

## Overview

The application combines robot control and multimedia features into a single graphical interface. Through Firebase Realtime Database, it communicates with an ESP32 module that acts as a bridge between the desktop application and the robot hardware.

Features include:

* MP3 playback and playlist management.
* Song selection through a graphical interface.
* Display of song metadata (title, artist, and album).
* Playback progress visualization and control.
* Manual MBot movement controls.
* Wireless communication with the robot through Firebase.
* Support for commands received from an infrared remote control.
* OLED display updates showing information about the currently playing track.
* Sensor-triggered actions generated by the MBot platform.
